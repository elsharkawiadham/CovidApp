Project Approach

This project explores global COVID-19 impact using an interactive map to help users quickly understand how different regions were affected.

What the Visualization Shows

The map displays cases or deaths per country using color intensity, allowing easy comparison across regions.

Data Selection

Some data points were incomplete or inconsistent. To ensure reliability, only the most recent record for each country was used.

Why This Matters

This approach ensures a fair and clear comparison between countries, avoiding misleading results from missing or outdated data.
